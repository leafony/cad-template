Leafony Leaf

Leafonyの拡張リーフを設計するためのKiCad 10.0用プロジェクトテンプレートです。
A KiCad 10.0 project template for designing Leafony expansion leaves.

収録内容 / Included in this template

  • PCB: 基板外形、Leafony bus接続部、取り付け穴、銅箔ゾーン禁止領域、デザインルール。
    Board outline, Leafony bus contacts, mounting holes, copper zone keepouts, and design rules.
  • 回路図 / Schematic: Leafony busシンボル、電源、信号名ラベル。
    Leafony bus symbol, power connections, and signal labels.
  • ライブラリ / Libraries: Leafony busのシンボルとフットプリント。
    Leafony bus symbol and footprint libraries.

基板仕様 / Board specifications

銅層 / Copper layers4 (F.Cu / In1.Cu / In2.Cu / B.Cu)
基板厚 / Board thickness0.8 mm
接続部 / Bus contactsCN1: F1-F29 / B1-B29

使い始める / Getting started

KiCad 10.0と標準ライブラリを使用してください。新規プロジェクトの作成後、プロジェクト固有のシンボルライブラリに lib/Leafony.kicad_symをLeafonyの名前で登録します。 フットプリントライブラリは登録済みです。
Use KiCad 10.0 with its standard libraries. After creating a project, register lib/Leafony.kicad_sym as Leafony in the project-specific symbol library table. The footprint library is already registered.
